# Suyashaa Vaidya — Portfolio

An interactive 3D-room portfolio (React + TypeScript + three.js) with a retro "suyashaa.os" desktop inside the monitor.

- `npm install`
- `npm run dev` — local dev server
- `npm run build` — type-check and build into `dist/`

Structure: `src/data/content.ts` holds all text, `src/three/createRoom.ts` the 3D scene, `src/apps/` the desktop windows.
